
# End-to-End OTIF Data Engineering Pipeline

## Project Overview

This project demonstrates an end-to-end data engineering workflow using simulated ERP supply chain data.

The pipeline aims to ingest, transform, validate, and prepare operational data for business intelligence and reporting.

## Technologies

- Python
- Pandas
- SQL
- SQLite
- Power BI
- GitHub

## Pipeline Architecture

Source Data → Ingestion → Transformation → Data Quality Validation → Data Model → Power BI

## Business Focus

On-Time In-Full (OTIF) delivery performance analysis.

## Data Source

Simulated ERP extracts covering orders, customers, products, and deliveries.
